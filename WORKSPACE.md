# Workspace rules (read before doing anything)

## Structure
- data/raw/      : original inputs. NEVER modify. Record source URL + download date in data/metadata/SOURCES.md
- data/processed/: generated by code only; must be recreatable
- src/           : reusable functions
- workflows/     : numbered steps (01_qc.py, 02_normalize.py, ...) that run raw -> figures
- configs/       : ALL parameters (YAML). No hard-coded parameters in code.
- environment/   : exact package versions (environment.yml / requirements.txt)
- results/, figures/ : outputs, regenerated by workflows
- reports/       : write-ups; every claim cites the figure/result file that supports it

## Rules
1. Every parameter lives in configs/*.yaml, including random_seed.
2. Record package versions in environment/ whenever a package is added.
3. Log every analysis decision (and why) in reports/DECISIONS.md.
4. Commit to git after each meaningful step with a descriptive message.
5. The full analysis must rerun from data/raw with one command.
6. State the experimental unit (patient/sample vs. cell). Don't treat cells as independent replicates.
7. Check for confounding (e.g. treatment vs. batch) before drawing conclusions.
