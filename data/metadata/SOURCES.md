`workflows/run_all.sh`.

To fill in the checksum column:

```bash
shasum -a 256 data/raw/<file>
```

## Required columns

Whatever the format, the pipeline needs these per cell (set the column names under
`keys:` in `configs/scrna.yaml`):

- a **sample** identifier — the experimental unit for every group test
- a **response** label with exactly two levels (e.g. `R` / `NR`)
- optionally **patient** (if a patient contributed more than one sample), **timepoint**
  (enables the paired pre/on-treatment test), and **batch** (enables the
  response-vs-batch confounding check)

Sample-level columns may instead live in a CSV with one row per sample, pointed at by
`paths.sample_meta`; `src/data_io.attach_sample_meta` joins it onto the cells and fails
if any sample in the matrix has no metadata row.

The matrix must hold **raw counts** — `src/data_io.assert_raw_counts` rejects
pre-normalised input, because the pseudobulk DE step in workflow 05 sums counts and
cannot be run on log-normalised values.
